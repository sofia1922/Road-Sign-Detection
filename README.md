# 🚦 Road-Sign-Detection — Детекція та класифікація дорожніх знаків

**Road-Sign-Detection** — це інтелектуальна система комп'ютерного зору (Computer Vision) на базі сучасної архітектури **YOLOv8**, призначена для автоматичного виявлення та класифікації дорожніх знаків у реальному часі. 

Проєкт розроблено в рамках навчального курсу з глибокого навчання (Deep Learning) та орієнтовано на розгортання в системах допомоги водію (ADAS) та автономному транспорті.

---

## 📌 Основні можливості

* 🎯 **Виявлення 4 класів знаків:** `Traffic Light` (Світлофор), `Stop` (Знак «Стоп»), `Speedlimit` (Обмеження швидкості), `Crosswalk` (Пішохідний перехід).
* ⚡ **Висока швидкість інференсу:** Розпізнавання об'єктів за < 50 мс на одне зображення.
* 🎛️ **Інтерактивний Streamlit UI:** Веб-додаток із можливістю завантаження власних фото, зміною порогу впевненості (Confidence Threshold) та аналітичним звітом.
* 📦 **Модульна архітектура:** Чіткий розподіл на пайплайн підготовки даних, пайплайн тренування та сервіс деплойменту.

---

## 📊 Датасет

Використано датасет [Road Sign Detection (Kaggle)](https://www.kaggle.com/datasets/andrewmvd/road-sign-detection).

* **Формат аннотацій:** PASCAL VOC XML (автоматично конвертується в формат YOLO).
* **Кількість зображень:** 877 фотографій високої роздільної здатності з різними умовами освітлення.
* **Розподіл класів:**
  * Traffic Light — світлофори
  * Stop — знаки «Стоп»
  * Speedlimit — знаки обмеження швидкості
  * Crosswalk — знаки пішохідного переходу
