# Модель Road Sign Detection

Застосунок використовує навчену модель **YOLOv8n** з файлу `models/best.pt`. Для інференсу `inference.py` передає Ultralytics поріг впевненості `conf=0.37` і розмір входу `imgsz=640`. У Streamlit поріг можна змінювати для окремого зображення.

| ID | Назва в моделі | Назва в застосунку |
| --- | --- | --- |
| 0 | `trafficlight` | Світлофор |
| 1 | `stop` | Знак STOP |
| 2 | `speedlimit` | Обмеження швидкості |
| 3 | `crosswalk` | Пішохідний перехід |

`load_model()` завантажує ваги та перевіряє класи. `read_image()` враховує орієнтацію EXIF і перетворює зображення на RGB. `detect()` повертає розмічене RGB-зображення й список детекцій, відсортованих за спаданням впевненості. Кожна детекція містить назву класу, оцінку впевненості та координати прямокутника `(x1, y1, x2, y2)` у пікселях.

## Оцінювання

Датасет містить 877 зображень. Для навчання використано 613, для валідації — 176, для тестування — 88. Поріг впевненості 0.37 підібрано на валідаційній вибірці. YOLOv8n обрано після порівняння з YOLOv8s. Найскладнішим класом були світлофори.

Нижче наведено результати попереднього оцінювання на тестовій вибірці, які показує застосунок.

| --- | --- |

| Recall | 88.4% |
| mAP@0.5 | 90.2% |
| mAP@0.5:0.95 | 75.1% |
